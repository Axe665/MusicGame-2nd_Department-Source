# 已知限制与未实现功能

## 不在当前范围内

- `.mcz`、osu!mania 和 osu!catch 导入；`.lbp` 反向导入
- 接入 Malody 4.3.7 运行时
- 英文 UI、皮肤/世代编辑器、在线谱面平台
- 针对 10,000 音符的专项性能调优、MCP 对外接口
- 自由的三维飞行和大幅度镜头摆动（设计文档中列为非目标）；鼠标倾斜限制在 ±11°
- 自由手绘的边界轮廓：目前仍受简单凸轮廓和分段工具的约束（Red 已经支持在预览中手绘）

## 编辑器

- **边界只允许简单凸轮廓。** 边界编辑器采用「分段参数 + 控制点 + 预设」的方式，凹口、星形、折返、自交和局部半径变化过激都会被校验拒绝。`b` 插值按平滑曲线处理，语法保留。
- 局部 BoundaryEvent 仍然可用，但如果过渡过程中产生凹口或自交，同样会被拒绝。首版示例使用的是整环事件。
- 分音 UI 已经隐藏，`GridDivisions` 只保留内部兼容和其他吸附用途；音符固定吸附到当前小节线与竖线的交点。
- 拍号分母固定为 4；3/8、6/8 需要后续扩展 BeatUnit。
- 3D 预览中，环、舞台和刻度是 GPU 网格，音符和 HUD 仍是 2D 叠加层。这是为了保证编辑精度做的取舍。旧机器或集成显卡可以在「视图」页关闭 3D 环网格，回退到投影环线。
- 示例音频（`audio/demo_click.wav`）是脚本生成的节拍点击轨，不是正式曲目，可以在「谱面」页替换音频路径。

## 试玩

- 目前提供分档判定、事件日志和调试用的准确率与评级，**尚未采用正式的评分公式**，评分规则等设计文档冻结后再定。
- 触摸滑条的判定仍按平面轨迹进行：`touch_start` / `touch_end` 目前只做数据存储、镜像和检查器录入，33 路触摸区传感器还没有接入试玩判定。
- 滤镜是预览层的单 pass 近似实现：径向模糊只有 6 次采样，泛光只有 4 个方向，拖影不保留历史帧，`SHAKE` 是整幅画面偏移而不是逐元素抖动。

### 试玩时钟

- 试玩时钟不预测起播时刻：音频真正出声之后（`playback > 0`），才用**实际播放位置**锚定，所以误差不随平台和单次采样变化。原因是 `get_time_to_next_mix()` 可能变成负数，`get_output_latency()` 在 PipeWire 上实测有 29–58ms 的抖动。
- 驱动延迟只用于把「混音位置」换算为「听到的位置」：起播后 250ms 内取中位数，然后**冻结**，之后不再追随噪声。漂移校正带 4ms 死区，只处理真实的卡顿。驱动报告延迟为 0 时，自动退化为混音位置时钟。
- 缓冲大小和音频延迟的设置见 [媒体与音频](media-and-audio.md#音频延迟)。

## 导入

- osu!std 混合层是对可玩性的重新解释，不是原谱 1:1 还原：Tap 的角度按 Sentakki 的流向和大跳推进，slider 的轨迹由 Sentakki 的合法段链按剩余时长生成，不是逐点复刻原图。Path 的头和尾一起出现，尾部单独判定 Hit/Miss。
- `.osz` 多难度包会弹出选择框；包内难度没有音频时仍然可以导入，但预览没有声音。

## 媒体

- 非原生格式的音频和视频依赖 ffmpeg；**变速不变调的 `atempo` 预生成也需要 ffmpeg**，没有时倍速回退为变调播放并给出提示。原生的 WAV、OGG、MP3 和 OGV 在没有 ffmpeg 时仍然可以使用。仓库内置了一份 ffmpeg，见 [媒体与音频](media-and-audio.md#内置-ffmpeg)。
- BPM 和 offset 的自动识别结果只是初始值，半速/倍速和弱起前奏仍需人工确认。
- 视频只是背景层，音频是唯一的判定时钟。
- 音符速度是会话级选项，不写入谱面。
- 音量滑杆是会话级的，不写入谱面或配置文件，重启后回到 100%。
