# 编辑器

本文说明主编辑器的画布、音符编辑和检查器。环形状和镜头动画见 [环编辑器](ring-editor.md)，各音符的外观和含义见 [音符](notes.md)。

## 画布

### 网格与参考线

- **小节线**：在顶部「网格 小节线」里填每拍等分份数 N（1–64）。小节线是**唯一的拍轴吸附目标**，随谱面保存。填 0、负数、小数或非数字时会提示「数据有误」。
- **角度格线**：在顶部「角度等分」里填 N，360÷N 必须是整数，默认 12，即每格 30°。画布上等距显示 N−1 条内部格线。填 7 这类除不尽 360 的值会被拒绝，并提示最近的合法值（8）。
- **纵轴**：左列显示连续拍号（1、2、3、4、5…），同时显示小节线、竖线、30° 特殊角度参考线和 BPM 线。
- 分音网格、右列分音选择器、顶栏 SNAP 和检查器的「分音」项都已隐藏。`GridDivisions` 只保留作内部兼容。

### 吸附

- **默认吸附到「小节线 × 角度竖线」的交点。**
- 顶栏「轨道吸附」复选框控制角度方向的吸附，默认勾选，随谱面保存。关掉后角度完全自由，包括 0°/360° 接缝处。
- 按住 **Shift** 时，本次操作两个轴都不吸附。
- 放置音符时直接吸附。拖动时音符跟手，**松手才回吸**。每颗音符各自吸到最近的格点，并且只回吸真的动过的轴：用 Ctrl 纵向拖动时，不会把角度拽到竖线上。单击选中不会挪动音符。
- **红区吸附**：拖红区本体时，时间窗起点吸小节线（时长不变），中心角按「轨道吸附」处理，弧宽（10–359°）不吸。同样是松手才回吸；新建红区时按下的那一下也会吸附。
- **预览光标**：判定环内整片区域和环外缓冲区都会吸附到最近的 u，放置音符时不必精确压在环线上。

### 缩放与方向

- **纵向拉伸**：顶部「纵向拉伸」可以输入 0–10 的整数或小数，也可以拖滑条。每个 bar 的高度变为原来的 `1 + n×0.5` 倍，小节线等比拉伸，音符头和图标尺寸不变。Ctrl+滚轮以 0.1 为步长调节，到达边界后继续滚动不会再变。
- **滚轮**：往上滚是页面往上走（回到更早的拍），往下滚是继续往后。时间从下往上排时也按这个规则换算。
- **写谱方向**：画布右上角的「从上往下」开关默认打开。关闭后整个写谱区上下翻转，时间向上流动，后出现的音符在上方。翻转状态保存在谱面的 `editor.flow_down`。翻转后，批量复制或剪切时的半透明待粘贴音符也会同步倒转。

### 命中优先级

- 指针命中的是离指针**最近**的部件，而不是谱面里先遍历到的那个。
- 宽度手柄和尾巴手柄优先于「拖动整条」。手柄的命中范围固定为 12px，不随弧宽缩小，窄音符也抓得到。
- Bell 的命中区按画出来的整条金键计算；点住 Anchor 或 Bell 的本体就是拖动位置。
- 音符工具下点击已有音符时，优先选中这颗音符，不会叠加新音符。待复制的半透明预览不参与命中。
- 判定命中前，先按指针所在行剔除无关音符。在 1500 音符的谱面上，按下延迟从 20–50ms 降到 1–7ms。

## 放置音符

- **工具保持**：放置 Tap、Hold、Path、Trace、Anchor 或 Bell 后，工具保持当前类型。Path 选完尾点后不会自动切回选择工具。按 Esc 取消当前音符类型和待放置的 Path。
- **Hold**：第一次左键确定起点，移动鼠标后第二次左键确定终点。终点早于起点时自动交换起止时间。第二次点击不会触发音符选中保护。
- **Seek**：在画布上点选时间放置，再按 W 或 S 选择朝里或朝外。放置时先显示一条横跨 0–360° 的白线，按 W/S 后才显示箭头和方向色。
- **Path 手绘**：绘制过程中只显示**原始鼠标轨迹**（屏幕坐标直接画在光标层，不投影，也不重绘整层预览），期间不做光标吸附。松手后才投影到环平面并定型，依次做：RDP 简化（约 2–3px）→ 在 40° 以上的拐角处切段并固定 → Chaikin 平滑 → 等弧长重采样（不超过 96 点）。头尾点不动；`db` 按弧长重新计算，否则画得慢的一段会变成滑得快的一段。

## 选择

- **框选**：右键按住拖动进行框选。右键确定起始时间，此时用滚轮上下移动编辑区不会改变起点；左键确定结束时间，起点晚于终点时自动交换。左键松开结束选择，不会放置音符。
- 框内或与框相交的音符都会被选中，包括 Hold/Trace 的身体、Path 轨迹、音符圆头和头尾。
- 按住 Ctrl 左键单击音符，可以切换该音符的选中状态，并阻止放置操作，可以连续加选或取消。
- 右键单击音符、红区或事件会直接删除；右键按住拖动仍然是框选。

## 拖动与手柄

### 拖动音符

- 在时间线画布上，**任何工具**下按住已有音符拖动，都能修改拍位和角度，不用先切到选择工具。Shift 锁定拍位只转角度，Ctrl 只改拍位。
- 拖动时音符跟手，松手才回吸到「小节线 × 轨道竖线」（按 Shift 时本次不回吸）。Hold 和 Path 的尾巴、Path 的尾部角度跟着一起移动；拖尾巴或改长度的手柄是边拖边吸。
- 在左侧环预览里，选择工具下按住音符拖动**只改角度**，跨 0°/360° 时连续变化。多选时只转按住的那一颗。

### 画布手柄

- 选中 Tap 或 Hold 后，弧带两端出现白色方形手柄，指针靠近时变为左右缩放光标，拖动直接改宽度。宽度上限按「画出来的弧宽不超过 360°」夹取，大小 Tap 的 ×1.5 也不会把它推到 540°。
- Hold 尾部的圆形手柄只改结束拍。
- Path 头尾的白圈：横向拖动改头角或尾角，纵向拖动改起始拍或结束拍。头部至少保留 0.25 拍，尾部不动拍位。Path 头尾不提供宽度手柄，宽度在检查器里改。
- 弧线 Path 和 Hold 选中后，可以在预览中拖动青色的体节点。五角星 Path 没有可拖节点。

### Anchor 与 Bell

- **Anchor**：按住即可拖动，同一 `pairId` 的两颗整对平移，保持同拍和夹角。松手时**整对旋转吸附**：id 较小的那颗吸到轨道竖线，伙伴跟着转同样的角度，所以 180° 夹角不会被吸歪。奇数等分时伙伴可能落不到格线上，几何上无法两全。任一颗锁定时整对都不吸附。
- 在环预览里拖 Anchor 同样是整对旋转并回吸。在检查器里修改拍位或角度会同步到伙伴；旋转 90° 时伙伴一起转。
- **Bell**：按住本体拖动位置；选中后拖两端的白色手柄改弧宽（24–30°，按 u 1:1 换算，约 0.57°/px）。

### Limit 红区

- 选中后在内部拖动，会平移角度和时间窗：时长不变，起点不早于第 0 拍。
- 拖上下两条边上的白色手柄改宽度：对边基本不动，中心角度只移动一半，上限 359°。
- 在预览里用 Limit 工具时，横向拖改角度，纵向拖改时长，最多 4 拍。

### Path 造型拖拽

在 3D 预览中用选择工具：

- 拖 Path 尾巴：径向改尾部离心（centrifuge），切向改尾角。
- 拖轨迹中点：改轨迹轴长（axis）。

拖拽和检查器用的是同一套 setter，不会直接改 trace 点，所以滑条和图形始终一致。

## 剪贴、镜像与 ID

- **批量剪贴**：选中音符后按 Ctrl+C 复制或 Ctrl+X 剪切，半透明预览会跟随鼠标所在的时间。按 Ctrl+V 粘贴，Ctrl+A 镜像粘贴。
- 粘贴时重新分配唯一 ID，并按落点重排拍位和角度；落点冲突时沿角度轨道避让。粘贴成功后清除预览，并选中新音符。
- 右侧的多选区块会显示这些快捷键的提示。
- **镜像**：把音符角度加 180°，超过 360° 时从 0° 回绕；同时旋转 Bell 的 `center_u` 以及 Path/Trace 的平面坐标。镜像时触摸区 A↔B、D↔E 自动对调。
- **音符 ID**：整张谱从 0 开始按拍位升序编号；同一拍内按角度升序，同一拍的 Seek 排在最后。读取、保存、新建和复制之后都会按这个规则重排，Path 链的引用同步重新映射。

## Path 编辑

### 检查器参数

Path 的检查器只保留两个造型参数：

- **尾部离心 centrifuge**：0.00–1.00，有输入框和滑块。
- **轨迹轴长 axis**：−2.00–2.00，有输入框和滑块，另有 −1 / L / 1 三条可点击的锚定线。axis 是轨迹中点到头尾直线的有符号距离：0 为直线，负值为镜像。中点越出内圆环时，自动收紧到最近的合法值。

旧的尾半径、尾角度、尾宽度、容差、采样、滑动速度、判定点、擦除和星星颜色等控件都已隐藏，但对应的旧数据仍然可以读取（见下文「兼容」）。

在「路径造型」里可以在弧线和五角星之间切换。五角星会在环内画出五条弦，头尾圆环仍落在环上，中段判定仍然沿头尾弦进行。

### 等待拍数

在音符属性的「等待拍数」里设置落点到起划之间的间隔，支持小数拍，默认 0。等待时间包含在开始拍到结束拍的总时长内，所以增加等待会缩短滑动时间。

紧凑谱面编码会保存等待时间，并兼容没有这个字段的旧谱面。在支持保存之前就已存盘、因而丢失的等待值，需要重新设置或重新导入。

### 启动指示

在「设置 → 显示 → Path 启动指示」或试玩暂停菜单里选择，预览和试玩共用，选择会自动保存：

- **环形进度**（默认）：从头部落点开始，到等待结束时填满。
- **淡蓝收缩圆环**：在等待期间从透明渐显，从原头部圆环的 2.5 倍半径开始收缩，在启动时恰好回到原有大小。
- **关闭**

起划后 160ms 淡出。等待为 0 时不显示倒计时。启动指示不改变判定容错。旧设置里的渐显、变色和组合模式会自动回退为环形进度。

### Path part（多段链）

在谱面编辑区右键 Path 尾部，可以创建下一段（这个右键不会触发框选）。原 Path 记为 part0，新段为 part1，依次链接；蓝色的尾部和头部表示衔接处。

各段可以分别编辑。预览中只有 part0 的头部有星星，星星沿整条链移动，头部圆圈的动画缩小一半。整条链的启动指示使用 part0 的等待时间。

### 兼容

- 旧版 demo 已改写为 `centrifuge` / `axis` / `trace` 新字段。读取其他旧谱面时同样在加载阶段迁移，显式写出的旧轨迹也会补全新字段。
- 擦除区间、旧视觉点等字段仍然可以读取，只是新界面不再显示这些控件。
- 旧版自定义星星颜色的 RGB 数据（`"rgb"`）仍然保留兼容。

## 检查器

### 通用行为

- 在右栏任意位置上下滚动都会翻页（向上滚动时页面上移）。数字框、滑条和下拉框不会吞掉滚轮，也不会被滚轮顺手改值。「BPM 点」列表和可编辑文本仍然各自滚动。
- 检查器里的红字错误和状态栏错误都可以点击，跳转到对应的音符。校验错误不会阻止保存。

### 音符页

- **类型卡**：检查器上方是一排浅色切角卡（黑色背板，选中时为黄色），显示图标、标签和快捷键，点击即可切换工具。
- **Tap**：「长度倍率 ×l」可调 0.00–1.50 l（两位小数），实际弧宽 = 基础宽度 × 长度倍率。改离 0.50 就自动成为「大小 Tap」；点「恢复普通 Tap（0.50 l）」可以还原。长度为 0 时仍保留一个点状标记。长度体系见 [音符](notes.md#长度体系)。
- Tap 和 Hold 都有通用的「宽度」行。
- **Hold**：选中时显示俯视扇形预览。扇形角度等于当前实际弧宽，身体按 1 拍的样本展示，下方标注「弧宽 xx° · 时长 x.xx 拍」。
- **Bell**：带实时形状预览。

### 演出修饰

检查器的「演出修饰」组可以给每个音符加这些参数：

| 字段 | 范围 | 含义 |
|---|---|---|
| `hs` | 0.2–4 | 音符自身的下落速度 |
| `sv` | 0.25–4 | 滚动倍率 |
| `head_speed` | 0.25–4 | Hold / Path 头部速度 |
| `spawn` | 0–1 | 出生半径：0 从环心长出，1 直接出现在判定环上 |
| `bounce` + `bounce_dir` | 0–2 | 落点弹跳幅度，方向可选内凹或外凸 |
| `touch_start` / `touch_end` | A–E | Path 的触摸区端点，自动换算到 33 路传感器 |

这些字段都通过 `note_extras` 旁挂保存，不改变紧凑谱面代码，旧谱面不受影响。

音符透明度不再单独设置，统一使用组透明度。HS / SV 的编辑入口已隐藏，但已有谱面里的数据仍会保留和读取。

### 时间页

时间页参考 osu! editor 的布局，按 F6 打开。同一页里包含：

- 基准 BPM，带 ×2 / ÷2 按钮
- offset：可以在迷你波形上直接拖动对齐
- BPM 点列表：双击跳转
- 选中 BPM 点的起始拍、BPM 和拍号（分子 1–16）
- 在播放头处加 BPM 点、删除、把播放头设为起始拍
- 「改 BPM 时保持后续内容的毫秒位置」开关

Tap Tempo 和固定预读已经删除。时间页只显示和编辑当前组的 BPM 点，编辑区也只画当前组的 BPM 线。

### 组页

「组」页位于「谱面」页左侧，默认是组 0。

- 每个组记录基准 BPM、透明度（0–255）、True/False 状态和音符总数。
- 音符可以切换所属组。**False 音符只作装饰**：计入组的音符总数，但不参与判定和准度计算、公共角度校验和打击音效。假 Path 隐藏轨迹，保留头尾，星头在落点处用一拍时间淡入。
- 当前组正常显示，可以编辑；其他组以 25% 的标记显示，点击其他组的音符会提示它所属的组。
- 每个组右上角有「－」删除按钮。删除组会同时移除组内全部音符，并把后续组以及前移后的组内音符统一重新编号。
- **组速度**：从组 1 开始，速度以组基准 BPM 为参照。当前 BPM 高于基准时视觉速度变慢，低于基准时变快（`速度 × 变BPM / 基准BPM`）。不同组可以用不同的 BPM 和变化点实现差速。组 0 是默认组，下落时间固定为 1 秒。
- **组透明度**：通过组 alpha 在预览和试玩绘制中生效，不改变编辑区的显示。

### 谱面页

只保留标题、曲师、谱师、难度、音频和视频路径，以及保存按钮。

### 视图页

- 「正对镜头（忽略倾斜）」：默认开启，试玩时环面始终正对相机。需要作者设定的镜头时可以关闭。
- 「3D 环网格」：默认开启。关闭后回退为投影环线，适合旧机器或集成显卡。

## 边界

- 分段曲线类型为 `l` / `s` / `si` / `so` / `b`，支持闭合和缺口、局部 BoundaryEvent、restore/hold、控制点拖动、双击拆分。
- 预设有圆、椭圆、竖椭圆和「切一刀」。
- 轮廓限制为**简单凸轮廓**：自交、非凸、星形、折返和局部半径变化过激都会被拒绝。详见 [已知限制](limitations.md)。
- 在预览窗里可以拖动边界控制点，双击分段进行拆分。

## 区域（Limit）

- 参数为时间、角度和宽度，时长上限 4 拍。
- 校验会检查同一时刻的公共角度减去限制区后是否仍有可打的位置。
- 预览表现和判定见 [音符](notes.md#limit-红区)。

## 歌曲导入与新建

- 「文件 → 导入歌曲 / 识别 BPM…」：选择音频后自动识别基准 BPM 和 offset，在弹窗里确认后写入时间页。
- 新建谱面时，选好音频后自动测量 BPM 和 offset。BPM 最多保留 3 位小数，只有 1 位小数时四舍五入取整；offset 保留 3 位小数。
- 识别算法、倍数校正和适用范围见 [媒体与音频](media-and-audio.md#bpm-自动检测)。

## 编辑器预听

- 运输条「音频」弹出菜单里有「音乐」和「音效」两个音量滑杆，分别控制 `Music` 和 `SFX` 总线。编辑器播放、试玩和打击音共用这两条总线的设置。
- 同一弹出菜单里的「打击音」开关：播放时按音符时间触发 Tap、Hold 头/尾、Path 头/尾、Anchor、Bell、Trace 的音效。它只影响编辑器，不影响试玩。
- 音符速度见 [试玩与判定](playtest.md#速度)。
