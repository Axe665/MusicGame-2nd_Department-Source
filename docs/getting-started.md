# 上手指南

## 环境要求

- [Godot 4.7.2](https://godotengine.org/)（Forward+ / Vulkan）
- 可选：`ffmpeg`。仓库已内置一份，见 [媒体与音频](media-and-audio.md#内置-ffmpeg)，一般不需要另外安装

## 运行

```bash
godot --path .
```

也可以用 Godot 4.7.2 打开 `project.godot`，再按 F5 或 F6 运行。

首次启动会载入示例谱面文件夹 `charts/夜に駆ける（示例）/`，里面是谱面 `chart.json`、音频 `music.wav` 和曲绘 `cover.png`。这张谱有 35 个音符、2 个 BoundaryEvent、2 个 Limit 和若干 RingState 关键帧。

### 命令行参数

| 参数 | 作用 |
|---|---|
| `--auto` | 试玩时开启 AUTO 自动演示 |
| `--open-tabs=a.set.json\|b.json` | 一次打开多个标签页。`.set.json` 按难度套组打开，其余按普通谱面 JSON 打开 |
| `--open-set=<set.json> --child-window` | 以子窗口打开一个难度套组。转谱窗口内部使用这个参数 |

不带 `--open-tabs` 时，编辑器读设置里的 `startup_tabs`，默认为空。

## 界面布局

- **顶栏**：左上是品牌标识和当前标签；右上是「文件 / 编辑 / 视图 / 插入」菜单组和黄色的「试玩 F5」按钮。「编辑 → 设置…」打开统一的设置窗口，包含画质、界面、音频和校准四页。校准向导只在设置窗口里，从试玩设置进入也会跳回这里。
- **左侧，约 47%**：事件轨和 u×时间画布。画布上显示波形、BPM 线、播放头、连续拍号、小节线和角度格线。
- **中间，约 24%**：音符类型卡，下方是检查器。检查器分为音符、区域、边界、事件、视图、时间、组、谱面等页。
- **右侧**：可折叠的 3D 预览，由 SubViewport、Camera3D、环网格和视频背景组成。拖左侧把手可以改宽度；齿轮菜单里可以收起 HUD、调试信息或整个预览。
- **底部**：运输条（播放、时间、进度、BPM、音符速度、循环、音频弹出菜单）和状态栏。

## 快捷键

### 播放与试玩

| 按键 | 作用 |
|---|---|
| 空格 | 播放 / 暂停 |
| Shift+空格 | 从头播放 |
| Ctrl+空格 | 循环播放 |
| F5 | 从播放头开始试玩 |
| Shift+F5 | 从头试玩 |
| Esc | 结束试玩、退出结算页或停止播放 |
| `[` / `]`（试玩中） | 判定偏移 −5 / +5 ms，范围 ±200 ms，顶部显示当前 OFF |
| F8（试玩中） | 切换 AUTO 自动演示 |
| F9（试玩中） | 开关 Path 输入诊断日志 |
| F10（试玩中） | 显示 Path 判定区域 |

点「试玩 F5」按钮后，底部有两个选项：**继续游玩**（从播放头开始）和**从头开始玩**（从第 0 拍开始）。在试玩中通过暂停菜单打开时，只显示「完成」。

### 文件与编辑

| 按键 | 作用 |
|---|---|
| Ctrl+N / Ctrl+O | 新建 / 打开 |
| Ctrl+S / Ctrl+Shift+S | 保存 / 另存为 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做，最多 200 步（按快照里的音符总量限内存，万音符谱约 12 步） |
| Ctrl+C / Ctrl+X / Ctrl+V | 复制 / 剪切 / 粘贴选中的音符 |
| Ctrl+A | 镜像粘贴 |
| A | 单个音符选中时原地镜像 |
| Delete | 删除选中内容 |
| F6 | 打开检查器的「时间」页（基准 BPM、offset、BPM 列表） |
| K | 打开环编辑器（也可以用「视图 → 环编辑…」） |

### 工具

| 按键 | 作用 |
|---|---|
| 1–7 | Tap / Hold / Path / Seek / Anchor / Bell / Limit |
| B | 边界编辑 |
| E | 事件 |
| H | HUD |
| Esc | 取消当前音符类型和待放置的 Path |

Tap 和「大小 Tap」已经合并成同一张类型卡，长度在检查器里调。

焦点在任意数值输入框里时，数字键 1–7 不会切换工具，而是正常输入数字。底部流速等输入框获得焦点后，播放、工具切换、删除等全局快捷键都会暂停生效。

### 鼠标操作

| 操作 | 作用 |
|---|---|
| 右键单击音符、红区或事件 | 直接删除 |
| 右键按住拖动 | 框选 |
| 右键 Path 尾部 | 创建下一段 Path part |
| Ctrl+左键单击音符 | 切换该音符的选中状态 |
| 滚轮 | 上下翻页 |
| Ctrl+滚轮 | 纵向拉伸，步长 0.1 |
| 双击预览中的分段 | 拆分边界分段 |
