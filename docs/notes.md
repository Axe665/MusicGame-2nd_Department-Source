# 音符

本文说明各类音符的语义、外观和预览表现。判定窗口和输入规则见 [试玩与判定](playtest.md)。

## 类型一览

| 类型 | 快捷键 | 输入 | 外观 |
|---|---|---|---|
| Tap | 1 | 任意键 | 可变角宽的切向宽条（粉红） |
| Hold | 2 | 按住起手键，只判头部 | 珊瑚红实心长条 |
| Path | 3 | 头部按键，之后鼠标沿轨迹滑动 | 星头、发车环、方向箭头轨迹、圆头端子终点 |
| Seek | 4 | 鼠标滚轮（只有朝向 `orien`：0 朝里，1 朝外） | 扩散圆环加朝内或朝外的箭头 |
| Anchor | 5 | 任意键，按 `pairId` 成对出现 | 紫色胶囊 + 菱形芯 |
| Bell | 6 | 光标贴住即可，不用点击 | 白描边金键 |
| Limit | 7 | 光标避开 | 深红锯齿扇区 |
| Trace | — | 鼠标沿手绘轨迹擦过 | 门框加游标 |

Trace 只用于手绘擦带，不再由 osu! 滑条生成。

所有音符以**八角舞台安全矩形**为游玩范围：手绘 Trace 落点时会被夹到安全区内，环上的音符保持在环内。

## 长度体系

- **l** 是旧版 Tap 与判定环重合时的条带长度，即 `note.width`。
- 普通 Tap 和 Hold 头都是 **0.5 l**。看到多长就能打多长：绘制和判定共用 `Note.arc_width()`。
- Tap 的长度可以在检查器里调到 **0.00–1.50 l**（两位小数），实际弧宽 = 基础宽度 × 长度倍率。偏离 0.50 时就是「大小 Tap」。长度为 0 时仍保留一个点状标记。JSON 里只有大小 Tap 才写 `sized` / `size` 字段。
- Tap 和 Hold 在环心出现时只有 **1/6 l**，飞近判定环时长到 1 l。Path 不受这套规则影响。

## 接近表现

- 所有音符（Tap、Hold、Path、Seek、Trace、Anchor、Bell）共用同一条下落曲线：出生在 1/6 环半径，判定拍正好落到判定环上，并随预读放大；轨迹和星尾一起长出来，不会原地出现。
- 星头和轨迹一起从圆心长出，随预读同步放大，没有单独的星星显现或启动延迟，尾判和轨迹同时到位。
- Hold 完成后用 0.24 拍渐隐。
- 所有音符的厚度和星头按环半径等比缩放。Tap、Path、Trace 统一使用 32px 外圈和 13px 主色。

## 各类音符

### Tap

可变角宽的切向宽条，颜色为粉红。宽度和长度规则见上文「长度体系」。

### Hold

- 只判头部。头部和 Tap 使用同一条「长度条」（`_draw_length_band`），缩放节奏也和 Tap 完全一致：环心 1/6 l，判定环 1 l。
- 主体是珊瑚红实心长条（`UITheme.HOLD`），和 Tap 的粉红同色系，和 Bell 的金色拉开距离。宽度等于判定弧宽，跨 0°/360° 时拆段绘制。
- 身体从**圆心**画到 **1.44R**，即旧版 0.28R→1R 长度（0.72R）的两倍，外端越过判定环 0.44R。飞入时同样跟着 `grow` 长出来。
- **叠放**：同一角度的连续 Hold 按时间做深度淡化，越晚越淡，最低 65%。身体和头尾分两遍画，所有头部都压在身体之上；最近要按的一颗额外带一层头带柔光。这些只影响画面，判定角度和时间不变。
- 旧谱里弯曲长条的 `visual_pts` 数据仍然保留，但不再参与绘制。

### Path

- 外观为星头、发车环、方向箭头轨迹和圆头端子终点。多条 Path 同屏时，另有反向箭头和白色的同押描边。
- 视觉尺寸放大两倍（`PATH_SIZE_SCALE`）：轨迹笔画、V 形箭头、星头、尾环和进度球都放大，轨迹几何和判定不变。
- Path 头部不画宽度红弧。宽度是判定参数，只在检查器里改。
- **身体画法**：在「设置 → 画质 → Path 画法」里切换。
  - **履带（粗，默认）**：实心带加内部箭头纹
  - **丝带（透）**：半透明宽带加一道亮边
- **星星颜色 / 轨迹颜色**：分开设置，轨迹不设时跟随星星。默认使用全局星色（舞萌蓝）。任意两条 Path 在**时间和盘面轨迹上**都重叠时，按同色系逐级压低明度来区分。
- **显示轨迹**关掉后只画星头，判定等同 Tap：只判头，没有尾环和尾判。
- **装饰 Path**（音符状态 False）显示完整轨迹，星星照常沿轨迹走，但不判定，滑动也不会擦除轨迹。
- 同屏超过 24 条 Path 时省略方向箭头和履带纹，只保留轨迹本体，避免小图元把帧时间吃满。
- 编辑方法见 [编辑器](editor.md#path-编辑)，判定规则见 [试玩与判定](playtest.md#path)。

### Seek

- 从 1/6 环半径处出现，贴着真实边界（椭圆、倾斜、变形的环都会跟随）线性长到环上。下落曲线和 Tap、Bell 相同，不做缓动；到达内圆环时判定。
- 环上一圈均匀分布的小箭头：朝里为冷蓝色，朝外为暖橙色。
- 圆圈本身不单独淡入，出现时就在下落曲线的起点。8 支箭头依次错开 8ms 弹入。
- 方向残影沿滚轮方向流动，速度为 40px/s，临近判定时提到 90px/s。
- 长出前整整一小节，环上先亮起判定弧作为预告：像呼吸一样一亮一暗，两拍一个周期，因此明暗频率始终是播放头当刻 BPM 的一半；最暗时仍留一层淡影，不会完全熄灭。拍号决定「一小节」的长度（拍号分子变小时预告也跟着变短）。长出后预告交给音符本体，判定前 300ms 再叠上就位高亮。
- 命中时用 80ms 向外扩 6% 并淡出；失误时变红闪两次。

### Anchor

- 紫色 Tap 胶囊，中间是一颗菱形芯（Tap 的中心圆点换成菱形），下落曲线、描边和材质都和 Tap 同一条。
- 宽度就是环上的胶囊长度：默认 30°，可在检查器里改到 8–120°（谱面格式见 [谱面格式](chart-format.md)）。判定区跟着胶囊变长，看到多长就能打多长。
- 两颗一对，通过 `pairId` 关联，靠近判定环时亮起一条淡紫双押线。编辑方法见 [编辑器](editor.md#anchor-与-bell)。

### Bell

- 白描边金键：金色核心、圆头和一圈细金色光环。弧宽 24–30°，和 Tap 到达环时的 31° 同级。
- 所有 Bell 都在判定环上，圆心不出现铃铛。舞萌的 C 区触摸也并入外环，角度继承时间上最近的音符。
- 旧谱里 45° 的 Bell 在载入时统一收敛为 30°。
- 在制谱器时间轴上，Bell 按弧宽画成白壳金芯的圆头金条，调色板图标为金键。
- 判定规则见 [试玩与判定](playtest.md#bell)。

### Limit 红区

- 深红色锯齿扇区，外缘有 1–3px 的撕裂效果和径向警戒线，带 LIMIT / LIMIT IN 标签和亮色外弧。
- **入场**：提前 max(400ms, 半个预读时间) 只显示轮廓，从内圈线性长到环上。
- **激活**：110ms 填满，70ms 环内白闪，之后以 1.2Hz 呼吸。
- **退场**：结束前 150ms 收束成一条细线。
- 判定规则见 [试玩与判定](playtest.md#limit-红区)。

## 预览画面

- **3D 预览**：默认开启 3D 环网格。环、八边形舞台、八束光、刻度、外圈和投影阴影都用 GPU 网格绘制；音符和 HUD 仍是 2D 叠加层。
- 相机投影支持 tilt、zoom、ellipse 和 rotation，另有鼠标倾斜和视差。
- 预览中还包括：固定预读 P(u,q,t)、单光标最近点、HUD 60° 弧、误差刻度和视频层。
- **视觉风格**：石墨黑加安全黄的 UI，浅色切角音符卡，深空径向渐变背景。圆环是终末地式分段圆环：白色开口弧、琥珀色细环、凹槽刻度和暗色外圈，不再使用八角外框和八束光。另有圆盘刻度、十字准星和音符投影。音符保留珊瑚、琥珀、青、薄荷、紫、金、红等语义色。
- 试玩时环放大到屏幕短边的约 86–88%，环外的整片区域仍然可以判定。
- **光标**：白色外环、青色内环、旋转弧、深色描边和拖尾。预览内始终隐藏系统光标，绘制自定义光标。
- **环**：正对镜头，叠加鼠标倾斜和视差。
