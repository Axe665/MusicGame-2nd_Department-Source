# 环编辑器

环编辑器在时间轴上编排判定环的形状、镜头和演出指令。

## 打开与布局

在主界面按 `K`，或选择「视图 → 环编辑…」打开；按 `Esc` 返回。

布局采用 Flash 式排布：上方是 3D 预览，左侧是形状库，右侧是属性面板，底部是一条全宽的时间轴。

## 时间轴

- **轨道**：两条主轨是**形状**和**镜头**。标尺下方常驻一条**音符轨**，按类型着色，Hold 和 Path 画出持续长度；点击音符会跳到它所在的拍，方便对齐音乐。底部的「辅助」区可以折叠，只读显示旧的边界事件和 BPM（BPM 仍在速度面板里编辑）。
- **帧格和段条**：拍线和小节线随缩放程度抽稀。关键帧画成方块（镜头帧是菱形），段条从本帧延伸到下一帧，段尾显示「过渡 N 拍」或「硬切」，最后一帧显示「保持到结尾」。
- **缩放和平移**：`Ctrl+滚轮` 以光标下的拍为锚点连续缩放，滚轮平移。`F` 适配所有关键帧，`Home` / `End` 跳到开头 / 结尾，`◀ 关键帧` / `关键帧 ▶` 在两条轨的关键帧之间跳转。
- **洋葱皮**：勾选后显示当前段前后各 N 帧的环轮廓，N 可调 1–5。

## 形状

- **过渡在目标帧之前完成。** 选中一段 A→B 并设「过渡 1 拍」，意思是 A 保持到 B 之前 1 拍，再用 1 拍变到 B；设为 0 就是在 B 拍硬切。新建的帧默认是硬切，谱师按段自行调整。
- 没有形状帧时，整首曲子都是基础圆；第一帧之前也是圆；删掉中间的帧时，由前一帧保持；最后一帧保持到结尾。
- `S0` 是锁定的基础圆，不能编辑或删除。需要自定义时，先「复制」一份再画。
- **「插入形状帧」**有三种方式：用当前轮廓新建形状、使用已有形状，或放一个圆。播放头处已经有帧时，插入会自动落到下一个吸附格，不会悄悄覆盖。选中帧的检查器里也有「＋ 在下一拍插入」，连续点击可以连续铺帧。
- 双击形状帧，或点「编辑形状（2D）」，打开画形板。`G` 切断或恢复缺口。
- 形状的约束（简单凸轮廓）见 [编辑器](editor.md#边界)。

## 镜头

- 镜头只保留两个参数：**推拉**（改变镜头距离，1.0 为标准）和**滚转**。环始终在画面中央，不做自由的 3D 飞行。
- 镜头帧默认整段平滑过渡，可以改短，或设为 0 硬切。滚转走最短的弧。
- 推拉和滚转会进入试玩和视频导出。
- 旧谱里的缩放、倾斜和椭圆字段保留兼容，但不再出现在镜头面板里。

## 选择与编辑

- 点击关键帧或段条选中；`Ctrl` / `Shift` 点击加选；在空白处拖动框选，可以跨形状轨和镜头轨。拖动任意一个选中的键，会把所有选中的键按拍整体平移。
- `Ctrl+C` / `Ctrl+V` 复制粘贴关键帧：以播放头为起点，保持相对间距，同一拍冲突时替换。`Del` 删除。
- 选中演出指令时，同一组快捷键复制整条指令（类型、持续拍数和参数）并粘贴到播放头，`Ctrl+X` 剪切。
- **右侧属性**（全部中文标注）：
  - 形状帧：拍、形状、入场过渡、缓动和曲线、缺口，以及打开 2D 画形板的按钮
  - 镜头帧：拍、推拉、滚转、入场过渡
- **曲线**：每段使用一条 cubic-bezier 曲线，可以拖动两个手柄，也可以选线性、缓入、缓出、缓入缓出预设。自定义曲线优先于预设名。

## 演出指令

演出指令共三类 32 条：`<JLINE>` 判定线（1 条）、`<TEXT>` 文本（2 条）和滤镜（29 条）。

### 编辑

- 指令放在环编辑器时间轴上单独的三行里：判定线、文本、滤镜。
- 双击空白处新增，拖动修改拍位。双击指令选中后，在右侧的「指令参数」里修改持续拍数、过渡曲线和各项参数。
- 数据保存在谱面 JSON 的 `commands` 数组里，旧版本读到时会忽略。

### 包络

- 每条指令都有三段包络：起手（attack）→ 保持 → 收尾（release）。
- 滤镜的「进入比例 / 退出比例」在「指令参数 → 包络」里用滑杆设，默认 0.25/0.25；只写数值，不解析 `True` / `False` / `Instant` 文本。
- `SHAKE` 这类瞬发指令在起点之后的 0.5 拍内生效。
- `KALEIDOSCOPE` 是开关型，但同样受持续拍数限制：从起点立即生效，到结束拍停止；`on=false` 表示在这段时长里淡出。
- `INVERT` 使用普通包络。
- 同名指令同时生效时，取最强的那一条。

### 旧名字

`TVNOISE`、`SHATTER`、`GAUSSIAN`、`TRAIL` 以前会折叠到故障/径向模糊，现在都是真实效果：旧谱面按新效果播放，不再折叠。`SPLIT` 仍是色差；Majdata 的横带错位用新增的 `STRIPS`。

### 预览中的表现

- **判定线**：画成横线，参数包括颜色、粗细、不透明度和 expand。
- **文本**：按归一化的 x/y 位置绘制。
- **滤镜**：通过一层全屏 shader 做后处理，作用在整块预览画面上。支持亮度、对比度、饱和度、色相、暗角、缩放、像素化、故障、反色、色调分离、色差、横带错位、涟漪、径向模糊、高斯模糊、万花筒、旋转、泛光、位移、抖动、着色、闪光、雪花噪点、玻璃碎裂和残影。多个滤镜现在会叠加。
- 没有滤镜生效时，不做全屏后处理。

`TRAIL` 会在启用时每帧抓一帧历史画面（子视口 + 上一帧纹理），关掉后整个子视口停止更新。`GAUSSIAN` 是 12 次采样的近似模糊，`SHATTER` 是径向裂纹位移，`STRIPS` 是 8 条横带交替错位，`SPLIT` 仍是独立 RGB 色差。都可以按包络进入/退出。

## 性能

- 时间轴拆成「静态轨道体」和「播放头覆盖层」两层，拖动播放头或播放时只重绘覆盖层。只遍历可见拍区间内的关键帧，帧格按像素密度抽稀。
- 拖动形状帧或镜头帧时，音符层暂时隐藏（10k 音符时重绘一次约 30ms），松手后恢复；环、红区、小节线和洋葱皮仍然跟随。
- 在 10k 音符、200 关键帧的条件下，`ring_key_drag` 的 CPU 中位数小于 1ms，`ring_all_zoom` 小于 0.1ms。
- 右侧属性页按选择的类型缓存，改滑块或步进时只同步数值，不重建中文 Label。环编辑提交时发出 `ring_changed`，不重建音符缓存、SFX 表和主检查器。
- 第一次打开某类面板时仍需构建一次控件（约 0.7–1 秒），之后同类选择都是毫秒级。
- 音符轨按音符版本缓存拍点，只绘制可见区间，音符过密时按步长抽样。

## 存盘格式

环编辑数据的存盘版本为 v3：

- 形状和镜头关键帧带稳定的 `id`、每段的 `curve` 和入场的 `morph`；镜头新增 `dolly`。
- v1 和 v2 文件照常打开：自动补 id，迁移镜头缓动，把旧的整段形变显式写成 span。
- 新版谱面不再同时写入旧的 `events`，所以删光关键帧后重新打开，动画不会回来。
