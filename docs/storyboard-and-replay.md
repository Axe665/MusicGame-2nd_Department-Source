# 故事板与回放导出

## osu! storyboard

### 导入

- 导入 `.osz` 时，如果包里有 `.osb`，或者 `.osu` 文件的 `[Events]` 段里内联了 Sprite / Animation，会一起解析。
- 支持的内容：
  - 图层：Background / Foreground / Overlay
  - 9 种原点
  - `F / M / MX / MY / S / V / R / C / P` 命令
  - 缓动 0–35
  - `L` 循环：解析时展开成绝对时间段
  - `Animation` 帧序列
- 素材按引用名解包到 `user://imports/<曲名>_<hash>/sb/`，路径记在 `chart.metadata.storyboard`。
- 也可以单独导入：用 osu! 的编辑器做好 storyboard，导出 `.osb` 和图片，再通过「文件 → 导入 → 故事板 (.osb)…」挂到当前谱面上。图片按文件名拍平，复制到 `user://storyboards/`。
- 实现移植自 ppy/osu 的 `LegacyStoryboardDecoder` 和 osu-framework 的 `DefaultEasingFunction`。

### 绘制

- **图层顺序**：整张故事板都画在 3D 判定环的**下面**，环、音符和光标始终在最上层。ReDIVE 这类带上下遮幅的故事板不会把环切掉。
- **时间基准**：使用 `chart.ms - offset`，和视频是同一套基准。
- **开关**：视图菜单和试玩设置里都可以开关「故事板」，设置写入 `settings.json`。
- **背景替换**：故事板的 Background 层里出现谱面背景图时，静态背景层自动隐藏，对应 lazer 的 `ReplacesBackground`。
- **坐标映射**：按 osu! 的 `ToScreenSpace` 规则，**按高度缩放，场地中心对齐屏幕中心**，不做 cover 拉伸。所以 1920x540 这类横条只占 75% 的高度，不会铺满全屏。谱面背景图始终垫在 storyboard 下面，和 stable 版本一致。
- **安全框**：故事板统一裁到 **854×480 或 640×480 的安全框**内。超宽背景左右多出的部分，在试玩、回放和导出里都不显示；编辑器画布会显示整张图，框外盖一层暗色蒙版，方便对位。宽屏判定除了看初始坐标，还看 `move/x` 命令，以及用 `V` 拉到 427（对应 854 的设计宽度）的白点遮幅。
- **加色混合**：`P,A` 加色元素走单独的 `BLEND_MODE_ADD` 图层（背景和前景各一层），alpha 压到 35%，防止几百张全屏图叠加后刷白。
- **编辑器内的小预览**：把整块 storyboard **等比缩小到能完整装下**（`storyboard_fit`），但 3D 环**保持面板满尺寸**，故事板只作为背景。试玩时仍按高度铺满。
- 切换标签页时，会调用 `Preview3D.invalidate_storyboard()` 让故事板层重新解析，避免沿用上一个标签页的画面。

### 性能

- 素材在后台解码，每帧上传。
- 采样频率**跟随帧率上限**：60 或 120 时每帧采样一次；垂直同步或不限帧率时按 60 采样；导出时按导出的 fps 采样。
- 按图层分桶，只遍历本层的对象；按 500ms 分桶，只遍历当前时间窗口里的对象；全透明的对象直接剔除。
- 命令查找带「上一条命中」缓存：播放时是 O(1)，seek 回退时用二分查找。线性缓动跳过曲线函数。
- 编辑器画布和预览共用同一份纹理缓存。

## 故事板编辑器

从「插入 → 故事板编辑器…」打开。

### 布局

编辑器是**全屏工作区**，排布和环编辑器一致：

- 顶部：标题、撤销/重做、保存/导出、关闭
- 左侧：对象列表和素材库
- 中间：大预览
- 右侧：选中对象的属性和命令面板
- 底部：**播放条、时间轴和操作说明行**

### 时间轴

- 默认**每层一行**：背景、失败层、通过层、前景、覆盖层、视频。展开一层后，显示该层的 sprite 行。
- 命令画成彩条，两端是起止菱形；`L` 循环块用斜线网纹标出，只读。
- 每一层都有**显示/隐藏**和**锁定**（锁定后不能点选或拖动）。它们只是视图状态，不进入撤销栈，再点一次即可恢复。
- 右上角的 `⋯` 菜单提供适配全部、跳转、跟随播放头、展开/折叠。
- 底部页脚显示当前时间、拍、总长、FPS 和吸附档位。

### 操作

- **点击标尺或行内空白**：跳到该时间。
- **单击命令条**：只选中对象或命令，不会把播放头拽回对象的起点。
- **双击命令条**：跳到它的起点。
- 拖动命令条中间整条平移，拖动边缘修改起点或终点。
- 滚轮上下滚动，`Ctrl+滚轮` 缩放，`Shift+滚轮` 平移。
- **节拍吸附**：关 / 1/1 / 1/2 / 1/4 / 1/8 拍，用谱面的 BPM 表换算。
- **撤销/重做**：快照存为 `.osb` 文本，最多 50 步。
- 改动实时反映到右侧预览，不用先存盘。
- 选中命令后，点「取消编辑 / 新建」可以退出「更新命令」模式。
- 「添加图片…」：选择图片，复制到故事板目录，然后新建对象。默认放在 Foreground 层、居中，在播放头处淡入。
- 「复制 / 删除 / ▲▼ / 撤销 / 重做」都有界面按钮。

### Esc 与关闭

- **Esc 按层级取消**：拖拽/框选 → 命令编辑 → 选中 → 关闭提示。只要还有东西可以取消，Esc 就不会退出编辑器。
- 未保存提示只有三个按钮：「保存并关闭 / 不保存并关闭 / 继续编辑」。连按 Esc 不会叠出第二层提示。

### 保存

- 「保存并应用」写回 `user://storyboards/edit_<hash>/storyboard.osb`，不会改动导入目录。第一次保存或添加图片时，自动把素材复制到编辑目录。
- 也可以用「导出 .osb…」导出。

## 背景明暗

画质页的「背景明暗」有 关 / 25% / 50% / 75% / 100% 几档，默认 100%，也就是原始观感，上限为 100%。

这一个系数同时压暗曲绘、BGA 和整张故事板，只影响画面，不影响判定环和音符。编辑器和试玩共用这个设置。

## 回放视频导出

在试玩结算页或菜单里选择「导出回放视频」。

### 渲染

- 用离线的真实 Playtest 逐帧渲染：时间由帧号决定，和机器快慢无关。
- 先把无声画面送给 ffmpeg；结束后再按谱面 offset，把音源和**打击音**封装成 AAC 192k 的音轨。打击音在离线判定时收集事件，按 `HitSfx` 的音量和音高合成一条 44.1k 音轨，再和音乐相加。
- 成品带 `+faststart`。
- 推拉和滚转等镜头动画会进入导出。

### 范围

- **从录制起点**开始导出：如果本局是从播放头开始玩的，就从那里开始导出，不会把没有玩到的段落判成 MISS。
- 到谱面内容结束为止（取音符、区域、事件和音频长度中的最大值），再加 2 秒。

### 还原录制状态

- 回放文件会记住录制时的**谱面镜像**，加载和导出时自动还原。
- **录制倍速**也会记下，再次回放时仍按当时的速度运行。
- 录制 hash 按原谱计算，所以镜像局也能正常回放和导出。
- 旧回放没有 `mirror` 字段时，用录制 hash 反推 `lr` / `rot180`。AUTO 局导出时跟随当前的试玩镜像。

### 可靠性

- 导出由离线逐帧驱动，切到别的应用（窗口失焦）时，不会像试玩那样自动暂停、把剩下的帧冻住。
- 导出途中窗口被遮挡或最小化时，等待帧会超时兜底。
- 成片会回读时长进行校验，对不上时直接报错，而不是给一个「已导出」的短片。
- 如果导出时重跑出的命中数、失误数或最大连击和录制时的结算不一致，提示里会直接写出差异。
