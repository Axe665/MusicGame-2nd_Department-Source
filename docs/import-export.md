# 导入与导出

编辑器可以导入 osu!std 和舞萌（Simai）谱面，可以浏览在线谱面库，也可以导出 `.lbp` v2。

导入外部谱面是一种**可玩性重解释**，不是对原谱 1:1 还原。为了单光标和单手可玩，导入时会做一系列转换和保护，下文逐一说明。

## 转谱流程

- 导入 `.osz` 或 `maidata.txt`，或者从在线舞萌谱面下载完成后，编辑器会先把来源里的**所有难度都转换好，存成一个套组文件**（`user://sets/<曲名> [导入].set.json`），再**另开一个窗口**（`--open-set=<set.json> --child-window`）专门编辑它。父窗口的谱面保持原样。
- 新窗口和普通编辑器一样，只是顶部左侧多一个「难度」下拉框，可以在套组的所有难度之间直接切换。标题栏显示 `<曲名> · <难度>`。在线谱面下载后，不在浏览器里选难度，统一在新窗口里切换。
- 新窗口的自动保存写到 `user://autosave_import.json`，不会碰主窗口的 `autosave.json`。
- 导入时，`.osz` 里的音频、背景和视频会解包到 `user://imports/`，音频仍可以用 ffmpeg 转码。
- 导入结束后用对话框显示导入报告，列出保留和丢弃的内容及原因。
- 包内的难度没有音频时，仍然可以导入，只是预览没有声音。

难度套组的文件格式见 [谱面格式](chart-format.md#难度套组-setjson)。

## osu!std

### 基本映射

- **circle** → 环上的 Tap，角度为连续的 u。
- **slider** → 环内平面 Path：头部是星头按键，之后沿轨迹移动，尾部进入尾区后按判定偏移结算。lazy 或过短的滑条 → Hold。
- **spinner** 跳过。
- 不做 8 轨吸附，也没有全平面模式。
- 同时解析 offset、BPM 和 B / L / C / P 曲线采样。

### 落道与流向

照搬 Sentakki 的做法：

- 8 条道，每条 45°（`_std_closest_lane` / `_std_lane_u`）。
- 流向用中点法（`_std_stream_direction`）：同向保持，共线归零，否则取角度差的符号。流内按 45° 步进。
- 大跳按两端的道差计算（`_std_jump_offset`）。
- 间隔超过 1 拍时，回到绝对位置。

### 滑条

- 按 Sentakki 的**程序化段链**生成（`core/sentakki_slide.gd`），不跟随 osu! 的控制点。
- 从 `Straight / Circle / V / U / Cup / Thunder / Fan` × 8 道 × 镜像组成的合法段表里，按剩余时长反复挑选段（条件为 `min_ms × (1 + 1/velocity) < 剩余时长`）。连续同向的圆弧不合法。
- 重复滑条按段链转成单向的 Path。
- 带 Sentakki 式的 wait 阶段：wait 从 1 拍开始减半，低于 0.5 拍时退回 Hold。
- 轨迹按弧长匀速采样。
- 生成的轨迹不是原图逐点复刻。

### 宽度补偿

Tap 和 Path 头的宽度按相邻音符的角度差和时间差自动加宽，密集流加宽，jump 收窄。无轨的环主要靠这一点来吸收 osu! 里在环上不可打的配置。

> 待核实：旧版文档先后记录过 45–75° 和 52–110° 两个宽度范围，`core/osu_io.gd` 中没有找到对应的常量。

### 鼠标保护

转换后只做两件事：

- 同一时刻的多押只留一颗，优先级为星星 > Hold > Tap。
- 星星的尾判和下一颗的头同拍时，把下一颗的头吸到前一条的尾部。


## 舞萌（Simai）

### 读取

- 支持 `maidata.txt`，来源可以是 `.zip` 或 `.txt`。可以直接选择解压后的 `maidata.txt` 或其所在文件夹，音频直接使用同目录下的 `track.*`；从 zip 导入时仍会解包并转为 OGG。
- 解析难度列表、offset、按钮角度以及 Hold/Slide 的时长。

### 映射

- Tap、Hold 照常导入；Break 转为加宽的 Tap；Touch 转为 Bell；Slide 转为 Path。
- Slide 形状按精确几何生成，不近似成圆弧：
  - `p` / `q` → U 形，`pp` / `qq` → Cup，`s` / `z` → 闪电，`V` → 经过点，`w` → 扇形中轴
- 链式滑条（如 `1-3q5-7`）拼成一条 Path；同头多星（如 `1-4*-6`）只保留尾部落点最顺的一条。
- 自交的 Cup 和闪电保留原形状，只有超过鼠标速度上限时才压短轨迹。
- Touch 的 A / B / D / E 区全部落在外圈，连续的铃铛沿同一个圆扫过。中心 Touch（C 区）和 Touch Hold 导入为圆心或中圈的 Bell，Touch Hold 忽略时长。

### 转谱优化（`ConvertOptimizer`）

舞萌谱面是为双手和多点触摸设计的，转为单光标时由 `ConvertOptimizer` 做以下处理。

**同刻与重叠**

- 同一时刻只留一颗，优先级为星星 > Hold > Tap > Bell；同类型时看哪颗更顺。
- 星星时间重叠时，前一条能缩短就缩短；缩不了，后一条只保留星头，降为 Tap。
- 缩短或截断后，把后一颗的头吸到前一条的尾部，形成一笔画。
- Hold 的尾巴撞到下一颗按键时缩短；不足半拍时降为 Tap。

**速度上限**

- 每条星星按 3600px/s 的鼠标速度上限压短轨迹。
- **滑条底线**：时长小于 160ms，或头尾弦长小于 0.6R 的滑条直接降级为 Hold 或 Tap，因为这样的 Path 玩家读不出「要滑」。240 BPM 下 1/8 拍的滑条就在这条线以下，120–180 BPM 的常规滑条不受影响。

**来回与折返**

- **A-B-A-B 交互**：严格在两个位置之间来回（不少于 5 颗、平均速度快于 2200px/s）的整段，锁定到一对相距 45° 的位置。连 45° 都追不上的（253px ÷ 间隔 > 2200px/s），整段收到第一颗的角度，光标不用来回甩。
- **叠键**：相邻角度不超过 45° 的快速 Tap 来回（不少于 3 颗，允许轻微漂移，单向扫台阶不算），整段收到第一颗的角度。
- 其余超过 45° 且快于 2200px/s 的折返，逐颗压成 45°。
- 压角和 Hold 降级之后，再补做一遍叠键处理，这一遍只叠键，不改其他内容。

**Bell**

- Bell 与 100ms 以内的 Tap 或 Hold 撞上时，吸到同一角度，因为一个光标不可能同时站在两处。
- **快速扫键段**：不少于 3 颗连续的 Tap，间隔不超过 45ms，每颗至少移动 10°，总跨度不少于 45° 的，一对一转成 Bell，用鼠标沿路线扫过去收取。同一角度的连打不转。
- **同角度连爆**：间隔不超过 60ms、不少于 3 颗的同角度连打，隔一颗删一颗（例如 19 颗/秒 → 约 9.5 颗/秒），仍然保持为 Tap。

**星星期间**

- 只保留落在星轨 0.30R 以内的 Tap、Hold 和 Bell。
- 不在轨道上的 Bell 直接删掉，因为一个鼠标没法同时跟着滑条又去接铃铛。

## 在线谱面

### 舞萌谱面

- 卡片列表显示封面、曲名、艺术家、难度色块、收藏和详情入口。搜索栏旁边的分段按钮在 adxdls 和 majdata 两个源之间切换。
- **majdata**：接口固定每页 30 条，底部可以上一页、下一页或输入页码。
- **adxdls**：第一次打开时按当前页懒加载封面（`bg.webp`）和难度等级（maidata），缓存到 `user://chart_cache/`，再次打开时立即显示。
- 点击卡片任意位置查看详情：谱师、上传者、全部难度、BGA 状态和大小。
- 下载时询问「带 BGA / 不带 BGA」；没有 BGA 的谱面直接下载无 BGA 版本。BGA 下载失败只提示，不会阻断谱面导入。
- 收藏写入 `user://chart_favorites.json`；「只看收藏」只筛选当前源。
- majdata 依赖外部的 `curl`，没有安装 curl 的机器无法下载。

### osu! 谱面

通过「文件 → 在线 osu! 谱面…」打开，是一个独立窗口，交互和舞萌浏览器保持一致。

**列表**

- **打开即显示「最新上架」**：镜像在空搜索时返回 ranked 谱面的时间倒序。只在第一次打开且没有列表时才拉取，编辑器启动时不访问网络。清空搜索框回到第 1 页。
- 卡片显示封面、曲名、艺术家，以及前 4 个「星数 + 难度名」药丸；超过 4 个时，末尾的「+N ▾」可以在卡片内展开。
- 每页 30 条，底部是「上一页 / 页码 / 下一页」。搜索镜像不返回总数，所以只显示「第 N 页」；翻回已加载过的页不会再次请求。
- 点卡片右侧的 ☆ 收藏谱面包，收藏写入 `settings.json`。

**详情与下载**

- 点卡片进入详情页：封面、原文曲名、谱师、来源和 tags、全部难度的星数、BPM、时长、游玩次数、收藏数、状态和包体大小。
- 根据谱面是否带视频，提供「带视频下载 / 不带视频下载」。实测镜像的「去视频包」和完整包是同一个文件，所以「不带」的实际做法是导入后删除视频文件、不绑定 BGA。
- 下载过程中显示已下载量、总量和速度。拿到 `.osz` 后，走和本地导入完全相同的转谱流程。

**过滤**

- 漏斗按钮展开一行过滤条件：**类型 / 语言 / 标签 / 只看收藏**。
- 类型和语言使用 osu! 官网的枚举（`genre_id` / `language_id`）。
- 标签按 `tags`、曲名和艺术家做 token 匹配：用空格或逗号分隔，token 之间是 AND 关系，忽略大小写。
- osu.direct 的搜索接口会忽略 `genre` 和 `language` 参数，所以这些过滤是在每页 30 条候选结果上本地进行的。

**搜索框**

除了关键词，还接受 `beatmapsets/<id>`、`beatmaps/<id>`、`/s/<id>` 形式的链接或纯数字 ID，会直接打开详情页。谱面 ID 通过 `osu.ppy.sh/osu/<id>` 里的 `BeatmapSetID` 解析为谱面包，不需要 OAuth。

**数据来源**

- 搜索使用 `osu.direct` 镜像，只列出带 osu!std 难度的谱面包。
- 封面来自 `assets.ppy.sh`，缓存到 `user://osu_covers/<id>.jpg`。同时最多 3 个请求，按需加载。
- 下载使用 sayobot，失败时退回 `osu.direct`。
- osu! 包里的 BGA 是 `.m4v`，已经加入直接解码的列表，不需要转码。

## 导出 `.lbp` v2

按设计文档第 7 章输出以下段落：

```text
[General] / [Video] / [Metadata] / [TimingPoints] / [BoundaryShapes]
[BoundaryEvents] / [ViewStates] / [Regions] / [Notes] / [Editor]
```

- 保留五角星 Path、Trace 的二维点、Bell、Anchor 配对以及颜色和锁定选项。
- Tap 和 Hold 写入实际的弧宽；Bell 的行尾带 `width=` 选项。

## 不支持的格式

- `.mcz`
- osu!mania、osu!catch
- `.lbp` 反向导入
- Malody 4.3.7 运行时
