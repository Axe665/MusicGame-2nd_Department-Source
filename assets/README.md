# 歌曲资源

本目录不包含歌曲音频。

运行游戏前，请把你自己的 MP3 文件放到：

```text
assets/track.mp3
```

要求：

- 文件名必须是 `track.mp3`
- 当前谱面按 **しーけー — アトロポスと最果の探求者** 制作
- BPM 230，时长约 157.76 秒（2:37）

## 为什么不提交到 Git

歌曲版权归原曲作者及相关权利方所有。`assets/track.mp3` 已加入 `.gitignore`，不会被上传到 GitHub。

如果这是私有仓库，且你拥有相应的使用/分发权利，可以自行决定是否强制添加：

```powershell
git add -f assets/track.mp3
```

公开仓库请不要提交这首歌的音频文件。
